# Etapa 5b — IMU (MPU6050) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Acordar o TFT por movimento (INT no GPIO 7) e detectar queda (pico ≥ 3 g seguido de 30 s de imobilidade) disparando a contagem cancelável de SOS, com o I2C protegido por mutex entre OLED e MPU6050.

**Architecture:** A lógica pura de detecção de queda fica em `lib/imu/fall_detector` (sem Arduino, testada no host). O barramento I2C ganha um mutex global `src/i2c_bus` (como `src/spi_bus`) usado pelo OLED e pelo IMU. A task `imu` (core 1, prioridade 1) dorme esperando a interrupção do GPIO 7, acorda o TFT via `uiWakeScreen()` e amostra o acelerômetro a 50 Hz apenas enquanto há movimento ou suspeita de queda.

**Tech Stack:** ESP32-S3, Arduino-ESP32 2.0.x, `Wire`, `electroniccats/MPU6050`, FreeRTOS, Unity.

**Spec:** `docs/superpowers/specs/2026-11-25-etapa5b-imu-design.md`

## Global Constraints

- Commits semânticos em português, **sem** `Co-Authored-By` nem "Generated with Claude Code".
- `lib/` sem Arduino, compila no `native` (`-std=gnu++17 -Wall`).
- Detecção de queda **sempre ativa** (não entra em Configurações nem na NVS).
- Pinos fixos (`src/config.h`): `PIN_I2C_SDA = 8`, `PIN_I2C_SCL = 18`, `PIN_MPU_INT = 7`. OLED em `0x3C`, MPU6050 em `0x68`.
- MPU6050 configurado com acelerômetro em `±8 g` (`4096 LSB/g`), giroscópio em standby (X/Y/Z) e sensor de temperatura desligado.
- Limiares padrão em `FallConfig`: `impactG = 3.0f`, `stillBandG = 0.25f`, `stillDeltaG = 0.15f`, `settleMs = 1500`, `stillMs = 30000`, `moveCancelMs = 300`, `cooldownMs = 60000`, `quietToSleepMs = 3000`.
- Todo acesso ao `Wire` (OLED e MPU6050) deve estar protegido por `i2cLock()/i2cUnlock()`.
- Se o MPU6050 não responder no boot, marcar `state().imuOk = false`, logar erro e encerrar a task limpa sem afetar UI/OLED/rádio.

## Review Focus

1. **Ruído isolado durante os 30 s de imobilidade:** uma única amostra fora da faixa de repouso (< 300 ms) não pode cancelar uma queda real. Teste no Task 1 (`test_brief_noise_does_not_cancel_still_wait`).
2. **Rebotes nos primeiros 1,5 s após o impacto:** movimento durante `Settling` não pode cancelar a entrada em `StillWait`. Teste no Task 1 (`test_rebound_during_settling_is_ignored`).
3. **Usuário pega o aparelho antes dos 30 s:** movimento sustentado ≥ 300 ms em `StillWait` cancela a suspeita e volta a `Idle` sem disparar SOS. Teste no Task 1 (`test_sustained_movement_cancels_fall`).
4. **Wrap-around de `millis()` (`uint32_t`):** cálculos de tempo devem usar subtração unsigned `(uint32_t)(now - since) >= dur`. Teste no Task 1 (`test_millis_wraparound`).
5. **Concorrência I2C e sensor ausente:** `oled.cpp` não chama mais `Wire.begin()` sozinho, ambos usam `i2cLock()/i2cUnlock()`, e `imuTask` encerra limpa quando `testConnection()` falha. Verificação no Task 2 e Task 3.

### Task 1: Detector de queda puro (`lib/imu/fall_detector`)

**Files:**
- Create: `lib/imu/fall_detector.h`, `lib/imu/fall_detector.cpp`
- Test: `test/test_fall_detector/test_main.cpp`

**Interfaces:**
- Produces:
  ```cpp
  struct FallConfig {
    float impactG = 3.0f;
    float stillBandG = 0.25f;
    float stillDeltaG = 0.15f;
    uint32_t settleMs = 1500;
    uint32_t stillMs = 30000;
    uint32_t moveCancelMs = 300;
    uint32_t cooldownMs = 60000;
    uint32_t quietToSleepMs = 3000;
  };

  enum class FallState : uint8_t { Idle, Settling, StillWait, Cooldown };
  enum class FallEvent : uint8_t { None, SosCountdown };

  class FallDetector {
   public:
    explicit FallDetector(const FallConfig& cfg = {});
    void onMotionWake(uint32_t now);
    FallEvent update(float axG, float ayG, float azG, uint32_t now);
    FallState state() const;
    bool wantsSampling() const;
  };
  ```
- **Regras de `FallDetector`:**
  - Magnitude `mag = sqrtf(ax*ax + ay*ay + az*az)`.
  - Variação entre amostras: `delta = sqrtf((ax-px)^2 + (ay-py)^2 + (az-pz)^2)` (na primeira amostra após construção ou `onMotionWake`, `delta = 0`).
  - Amostra considerada "imóvel" quando `fabsf(mag - 1.0f) <= cfg_.stillBandG` e `delta <= cfg_.stillDeltaG`.
  - `onMotionWake(now)` marca `sampling_ = true`, reseta `quietSince_ = now` e `hasPrev_ = false` (sem cancelar `Settling`/`StillWait`/`Cooldown` se já estiverem ativos).
  - Em `Idle`:
    - Se `mag >= cfg_.impactG` → entra em `Settling` (`stateSince_ = now`, `sampling_ = true`).
    - Senão, se imóvel e `(uint32_t)(now - quietSince_) >= cfg_.quietToSleepMs` → `sampling_ = false`; se não imóvel → `quietSince_ = now`.
  - Em `Settling`:
    - `sampling_ = true`. Quando `(uint32_t)(now - stateSince_) >= cfg_.settleMs` → entra em `StillWait` (`stateSince_ = now`, `moving_ = false`).
  - Em `StillWait`:
    - `sampling_ = true`.
    - Se não imóvel: se `!moving_`, marca `moving_ = true` e `moveSince_ = now`; se `(uint32_t)(now - moveSince_) >= cfg_.moveCancelMs` → cancela e volta para `Idle` (`quietSince_ = now`).
    - Se imóvel: `moving_ = false`. Quando `(uint32_t)(now - stateSince_) >= cfg_.stillMs` → entra em `Cooldown` (`stateSince_ = now`) e retorna `FallEvent::SosCountdown`.
  - Em `Cooldown`:
    - `sampling_ = false` após expirar ou durante o cooldown? Mantém `sampling_ = false` (não precisa amostrar durante cooldown) e ao receber `update` ou `onMotionWake` depois de `(uint32_t)(now - stateSince_) >= cfg_.cooldownMs`, volta para `Idle`.

- [ ] **Step 1: Write the failing tests** em `test/test_fall_detector/test_main.cpp`:

  - `test_below_impact_threshold_does_not_trigger`: pico `2.9f` g + 35 s imóvel → sempre `FallEvent::None`, nunca sai de `Idle`.
  - `test_impact_plus_30s_still_triggers_sos`: `onMotionWake(0)`, impacto `(0, 0, 3.2f)` em `t = 100` → `Settling`; amostras imóveis `(0, 0, 1.0f)` a cada 100 ms: em `t = 1600` entra em `StillWait`; em `t = 31500` ainda `None`; em `t = 31600` retorna `FallEvent::SosCountdown` e `state() == Cooldown`.
  - `test_rebound_during_settling_is_ignored` (Review Focus 2): impacto em `t = 0`, amostras violentas `(2.5f, 0, 0)` em `t = 500` e `t = 1000`, depois imóvel de `t = 1500` até `t = 31500` → dispara `FallEvent::SosCountdown`.

**Interfaces:**

- Produces:
  ```cpp
  // src/imu.h
  void imuStart();  // cria task "imu" (core 1, prio 1, stack 4096)
  ```
- **Detalhes:**
  - `src/state.h`: adiciona `bool imuOk = false;` em `SharedState`.
  - `src/imu.cpp`:
    - Constantes ajustáveis no topo: `kAccelLsbPerG = 4096.0f` (±8 g), `kSampleMs = 20` (50 Hz), `kWakeCooldownMs = 1000`, `kMotionThr = 20` (~40 mg, 2 mg/LSB), `kMotionDur = 2` (2 ms).
    - Configura `MPU6050 mpu(0x68)` sob `i2cLock()`:
      - `mpu.initialize()`; testa `mpu.testConnection()`. Se falhar: `LOGE("IMU: MPU6050 nao respondeu em 0x68")`, grava `imuOk = false`, `vTaskDelete(nullptr)`.
      - `mpu.setFullScaleAccelRange(MPU6050_ACCEL_FS_8)`;
      - `mpu.setStandbyXGyroEnabled(true)`, `Y`, `Z` e `mpu.setTempSensorEnabled(false)`;
      - `mpu.setDHPFMode(MPU6050_DHPF_5)`;
      - `mpu.setMotionDetectionThreshold(kMotionThr)`;
      - `mpu.setMotionDetectionDuration(kMotionDur)`;
      - `mpu.setInterruptMode(0)` (ativo alto), `mpu.setInterruptDrive(0)` (push-pull), `mpu.setInterruptLatch(true)`, `mpu.setInterruptLatchClear(false)` (limpa lendo `INT_STATUS`), `mpu.setIntMotionEnabled(true)`;
      - `mpu.getIntStatus()` para limpar latch inicial.
    - Marca `state().imuOk = true`.
    - `pinMode(PIN_MPU_INT, INPUT)` + `attachInterrupt(digitalPinToInterrupt(PIN_MPU_INT), onMotionIsr, RISING)`. A ISR (`IRAM_ATTR`) chama `vTaskNotifyGiveFromISR(gImuTask, &woken)` e `portYIELD_FROM_ISR(woken)`.
    - Loop da task:
      1. `ulTaskNotifyTake(pdTRUE, portMAX_DELAY)` (dorme em repouso).
      2. Sob `i2cLock()`: `mpu.getIntStatus()`.
      3. Se `!hasWoken || (uint32_t)(now - lastWake) >= kWakeCooldownMs`: `uiWakeScreen()`, `lastWake = now`, `hasWoken = true`.
      4. `detector.onMotionWake(now)`.
      5. Enquanto `detector.wantsSampling()`: lê `mpu.getAcceleration(&ax, &ay, &az)` sob `i2cLock()`, converte para `g`, chama `detector.update(ax / kAccelLsbPerG, ay / kAccelLsbPerG, az / kAccelLsbPerG, millis())`. Se `FallEvent::SosCountdown` → `LOGW("IMU: queda detectada, iniciando contagem SOS")` + `uiRequestSosCountdown()`. `vTaskDelay(pdMS_TO_TICKS(kSampleMs))`.
      6. Ao sair do laço: limpa `mpu.getIntStatus()` sob `i2cLock()` e drena notificação residual `ulTaskNotifyTake(pdTRUE, 0)`.
  - `src/main.cpp`: chama `imuStart()` após `uiStart(gSettings)`.
  - `src/debug_console.cpp`: mostra `imu=%s` no `printStatus()`, adiciona comando `fall` chamando `uiRequestSosCountdown()` e inclui `fall` na linha de ajuda.
